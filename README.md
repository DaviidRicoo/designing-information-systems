# 📐 Designing Information Systems

> **Universidad:** WSB Merito Gdańsk (Programa Erasmus+)  
> **Grado:** Ingeniería Informática de Software  
> **Área:** Análisis de Sistemas, Modelado UML y Arquitectura de Software  

---

## 📌 Descripción del Repositorio

Este repositorio reúne las prácticas, diagramas y proyectos de diseño desarrollados en la asignatura **Designing Information Systems**. El objetivo principal es aplicar metodologías de análisis de requisitos, modelado estructural y comportamental de software, y diseño conceptual de bases de datos para sistemas de información a nivel empresarial.

---

## 🛠️ Herramientas y Tecnologías

* **Modelado UML / Diseño:** Enterprise Architect / StarUML / PlantUML / Visual Paradigm / Lucidchart
* **Metodologías:** Agile, Scrum, Ciclo de vida del software (SDLC)
* **Estándares:** UML 2.x, Diagramas Entidad-Relación (ERD)
